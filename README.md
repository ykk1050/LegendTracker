# 대연롯데캐슬레전드 33평 시세판

호갱노노 공개 정보로 33평(전용 84㎡) 매매 매물과 실거래를 모아 꺾은선 그래프로 보여 주는 웹앱입니다.

- 주소: https://ykk1050.github.io/LegendTracker/
- 휴대폰: 위 주소를 열고 브라우저 메뉴에서 "홈 화면에 추가"를 누르면 앱처럼 쓸 수 있습니다.

## 어떻게 돌아가나
- GitHub Actions(`.github/workflows/collect.yml`)가 20분마다 깨어나 직전 수집이 45분 넘었으면 `collect.py`를 실행해 (GitHub 예약 실행이 자주 빠져서 이렇게 함) `data/db.json`, `web/data.js`를 커밋하고 GitHub Pages로 게시합니다. PC가 꺼져 있어도 됩니다.
- 바로 수집하려면 GitHub 저장소 → Actions → "매시간 수집 및 게시" → Run workflow.
- 60일 동안 저장소 활동이 없으면 GitHub가 예약 실행을 멈출 수 있습니다. 그때는 Actions 화면에서 다시 켜면 됩니다.

## 파일
- `collect.py`: 수집기.
- `web/`: 웹앱 (index.html, data.js, manifest.json, sw.js, 아이콘).

## 알아 둘 점
- 매물 수·향별·층별 호가 추이는 수집을 시작한 2026-11-07부터 쌓입니다.
- 같은 집을 여러 중개사가 올리면 한 집으로 세고, 가장 싼 호가를 씁니다.
- 실거래에는 동·호가 공개되지 않아 향별 거래량은 볼 수 없습니다. 층별은 됩니다.
- 아실에서는 "매물 추이"(단지 전체 일별 매매·전세·월세 매물 수, 2022-10부터, 평형 구분 없음)만 가져옵니다. 가격은 암호화되어 있어 가져오지 않습니다.
- 층 구분: 저층 1~10, 중층 11~22, 고층 23층 이상 (매물에 '저/중/고'로만 적힌 경우 그대로 씀).
